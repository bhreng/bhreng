Scope & working rules

This map covers documents Dan authored. Student work is out of scope — student-owned files on the school domain are excluded from this audit and from the rewrite, and student rosters, submissions and grades never enter the working conversation.

Nothing is written to Google Drive. Drafts and outputs are produced and kept locally for review. No existing file is modified, moved, renamed or deleted; superseded documents get archived, never removed.

What's working — don't touch this

The spine is sound. The seven technical DESE standards map one-to-one onto the seven hubs. That is a real design, it uses state language, and it should survive every rewrite.

Why the documents are bloated

Not just wordy prose. Four classification systems run in parallel, and every document restates all four.

15DESE Standardsstate-mandated
10Program Content Categorieslocal invention
5Foundational Pillarslocal invention
5Hub Topicslocal invention

The standards are non-negotiable and carry DESE's own vocabulary. The other three overlap with them and with each other — PCC 10 "Professionalism & Safe Ops" is substantially Standard 1 plus Standard 13 plus the S&O pillar; PCC 9 "Methodology & Planning" is substantially Standard 4. Each overlap forces another paragraph of cross-referencing in every document that mentions either.

Governing rule for the rewrite

DESE language wins over local coinage. Where a state term and an invented term mean the same thing, the state term survives. Invented vocabulary with no DESE equivalent — "Engineering Accounting", "Dual-Axis Framework", "Knowledge Consumption pillar", "a-la-carte learning environment" — gets replaced with plain description. Nothing is deleted; superseded documents are archived, not removed.

Four eras

The timestamps sort themselves cleanly, and they support the read that the older material is the truer material.

2019 – 2024

Original standards work

Priority Standards sheets, Eng Voc Standards by grade level, simplified frameworks PDFs. Pre-Gemini, pre-Dryer. Reference material for what the program actually did.

Sep – Dec 2025

The 2025 update — new standards, new co-teacher

Nine "2025 update to…" files plus the new DESE standards PDF and the highlighted-by-level docs. This is where the real mapping happened. Treated here as the load-bearing layer.

Jan 2026

The binders

Binders 5–8 and the standards alignment sheets. Consolidation of the autumn work into reference documents.

May – Jun 2026

The pathway hub layer

Seven hub guides, program reports, crosswalk, Gem directives, source migration tables. Densest Gemini output, most invented vocabulary, most aspirational claims. Highest rewrite priority.

Highlight colors are not readable as data

Blocked

Binder 8 encodes which level teaches which standard in highlight color. Text extraction returns the words without the colors, so the mapping is currently only readable by eye. An Apps Script pass over the document can read each element's background color and emit a standard-by-level table — turning the color coding into data the rest of the work can build against.

Migration table hyperlinks may be missing

Blocked

The Industrial Design source migration table lists 70 sources, but the Hyperlink column reads as the literal word "Link" on every row. If the URLs are embedded as Sheets hyperlinks they can be recovered by script; if they were never captured, the sourcing work needs redoing. This determines whether that pathway is days or weeks from publishing.

Proposed order of work

  1. Rewrite the program structure binder

    The binder that spells out the program's structure is the anchor document — every hub guide and report restates parts of it. A clean new version, in DESE language, gives everything downstream something correct to reference instead of re-explaining.

  2. Resolve the collisions

    Seven decisions, mostly one line each. Archive rather than delete. This stops the rewrite from being applied to the wrong copy of a file.

  3. Extract the highlight data from Binder 8

    Apps Script pass returning a standard-by-level table. Small, concrete, unblocks all curriculum mapping.

  4. Recover the migration table hyperlinks

    Same technique, different document. Determines whether Industrial Design is close to publishable or needs re-sourcing.

  5. Write the house style spec

    DESE language over local coinage; a glossary mapping each invented term to its state equivalent or to plain description; a rule for marking planned versus running. Applied to one sample guide for approval before it goes anywhere else.

  6. Rewrite the seven hub guides against the spec

    Including filling the Automation & Robotics stub. Teacher and program facing, per your call.

  7. Then populate the Classroom hubs

    The original goal. The builder script already exists and is tested; it needs correct content pointed at it.
