BHR Engineering Word List

One word per thing. Check here before naming something in a new document — the word has probably already been decided.

Rule: where the state has a word for it, the state's word wins.

Why this exists

Terms got re-coined every time a new document was written, because each document picked the best word available at that moment. The result is four names for the daily logbook and two for the same self-directed project.

A word list fixes that going forward: a new document can't invent a fifth name for the logbook, because the name is already settled here.

One deliberate divergence

DESE skill S3-e says "maintain an engineering journal." We say Engineering Logbook, because that is the name printed on the template students actually open. This is the one place we knowingly depart from state wording — so every document that mentions the logbook should state once that it satisfies the S3-e engineering journal requirement. The divergence is a choice, not an accident.

Two numbering schemes, both correct

The EDP

The binder names eight stages: Identify the Problem · Research & Brainstorm · Develop Solutions · Plan a Solution · Create · Test & Evaluate · Improve & Redesign · Present Your Solution. That is the canonical description of the process.

The logbook uses five status codes as daily shorthand: [PI] [DD] [FAB] [TE] [IR]. A student picking a code at 9am shouldn't have to split hairs between adjacent planning stages. Present Your Solution has no code because it's a milestone, not a daily state.

Both are right. Documents describing the process use the eight; documents about daily work use the five; anything showing both states the mapping.

Still to settle

Logbook rules

Four different rule sets are in circulation across the hub guides — a "Rule of 11" (Industrial Design), "17 strict rules" (Architecture/Civil), Kelley & Wicklein (Mechanical), and Kelley plus the Tesla-versus-Marconi case (Project Management). Same underlying practice, four presentations, different counts. A student in two pathways currently gets two rulebooks. One set needs to win.

Metacognitive codes vs EDP codes

The Project Management guide has students tag logbook entries with PI and AL — mixing an EDP stage code with a pillar abbreviation. The logbook's own five codes are all EDP stages. Two schemes using overlapping letters for different things; pick one.
