Standard S6 · Mr. Dryer

Software Engineering

Logic, code, and making a machine decide something.

Code in this shop is not an end in itself — it controls something physical, and physical things have voltage and torque and consequences. You write logic, then you prove on an oscilloscope that the logic is doing what you think.

New to this pathway? Start here.

Nothing on this page is compulsory and there is no order you have to follow. If you want a way in, this is the one I would take.

  1. Open Software developers — Occupational Outlook from Explore the Field, and ask yourself honestly whether that work appeals to you.
  2. If it does, pick one thing from Learn the Concepts — there are 7 to choose from — and actually finish it.
  3. Then go to Build Your Skills and do something with your hands. 10 options, and you do not have to take them in order.
  4. Write down what you did in your logbook, including what did not work.

Stuck, or want to talk it through? Ask Mr. Dryer.

Learn the Concepts

Is this something you study to understand how the work works?

Logic first, syntax second. Every one of these is testable on paper before you touch a keyboard.

Boolean algebra
Build expressions and verify them with truth tables. This is how you check a circuit or a conditional is correct rather than hoping.
Logic simplification
De Morgan’s theorem and simplification to reduce an expression to its minimum form. Fewer gates, fewer branches, faster response.
Flowcharting
Map the logic before writing syntax. A flowchart catches the error that would otherwise take an hour of debugging to find.
Number systems
Binary, decimal and hexadecimal conversion, and why hex is how memory gets discussed.
Reference
Brilliant for logic and computer science reasoning; Khan Academy for the supporting math.

Build Your Skills

Is this a procedure you practice until you can do it?

Credential of valueDemonstrated proficiency in Python, Arduino C, and PLC ladder logicBase requirement for every pathway: OSHA 10 — Construction

Three environments, because the job moves between them.

  • Python — algorithmic logic and data analysis with NumPy and Pandas; setting up an environment and managing dependencies.
  • Arduino — firmware in C, I2C and SPI sensor communication, serial monitor debugging.
  • PLC ladder logic through Festo LX — industrial control and computer integrated manufacturing.
  • Pulse width modulation to control hardware torque and speed.
  • Sensor calibration — a reading is worthless until the sensor is calibrated.
  • Step-through debugging rather than guessing at a fix.
  • Oscilloscope for signal timing and frequency analysis — how you verify PWM is actually doing what your code says.

Find a Project

Is this something you could go build?

Pick one and document the optimization, not just the working version.

Robotic arm control

Program an arm with an end effector to solve a real materials-handling problem. The constraint is the work envelope and the gripper, not the code.

Automated feed system

Sensors plus decision logic managing autonomous material flow. Decide what happens when the sensor is ambiguous — that case is the whole assignment.

Data analyzer

Build something in Python that inspects and evaluates system parameters and recommends a change based on the data.

Every project needs a before-and-after on your own code: show a logic simplification or algorithmic change, and give the measured improvement in response time. “It felt faster” is not a result.

Projects this shop has already run

Real briefs from other years, offered here as optional work. You do not have to be in that grade to take one on — ask first, then build it.

Gr 93ds Max against Maya, in three days

Learn enough of each to judge them. One simple object built in each, then a recommendation for which suits a specific kind of shop work and why. A software evaluation, written as an engineer would.

Gr 10Program the SumoBot

Sensors, reactions and strategy in Spike. The mechanical build is only half of it.
